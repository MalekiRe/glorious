# Documentation archive

**Status:** historical record  
**Authority:** none for current implementation or project status

This directory preserves documents that were useful in an earlier compiler,
tooling, tutorial, or planning era. They remain available for provenance and
design archaeology, but their paths, commands, code references, completion
claims, and measurements may be stale.

- `reports/` contains one-off audits, performance comparisons, worktree reports,
  and task snapshots formerly placed at repository root.
- `pre-stage0/` contains architecture, backend, tooling, and self-hosting
  documents for the removed pre-Stage0 compiler.
- `design-records/` contains superseded or incomplete design decisions that
  overlap current specifications.
- `proposals/` contains proposal fragments removed from the active navigation
  surface because they have stale links or ambiguous implementation status.
- `tutorial/` preserves the tutorial for the retired `grand`/`grandfmt`/old
  compiler workflow.

Archived documents are intentionally not corrected in place. Follow
[`../README.md`](../README.md) for current documentation and
[`../documentation-policy.md`](../documentation-policy.md) for precedence.
